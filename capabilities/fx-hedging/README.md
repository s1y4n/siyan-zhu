# FX Hedging

This folder contains the model specification and Excel workbook for the FX Hedging project in International Finance & Securities.

The project uses Scenario 9 (lab-instruments), where a U.S. company expects to receive EUR 5,100,000 in 182 days. The goal is to compare a forward contract, money-market hedge, and put option to determine which strategy best protects the company's future dollar cash flow.

Stage 2 will add `spec.md`, and Stages 3–4 will develop and populate `model.xlsx`.
